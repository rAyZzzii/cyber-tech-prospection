# Cyber-Tech Prospection

**Projet de veille et prospection de missions de formation en cybersécurité — Île-de-France**

## Structure

```
cyber-tech-prospection/
├── scripts/         # Scripts Python (veille, excel, mailing)
├── data/            # Fichier Excel source de vérité
├── reports/         # Rapports quotidiens exportés
├── README.md
└── requirements.txt
```

## Objectif

Identifier des missions de formation/vacations en cybersécurité dans les écoles supérieures,
universités et organismes de formation en Île-de-France, et contacter les établissements
ciblés pour manifester l'intérêt de Cyber-Tech.

## Organisation

- **Phase 1** — Veille et collecte des missions
- **Phase 2** — Alimentation du fichier Excel structuré
- **Phase 3** — Prise de contact automatisée
- **Phase 4** — Reporting et boucle continue (cron quotidien)
